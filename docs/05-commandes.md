# 🎮 COMMANDES - YTM GODAS V3

---

# 🎶 !sr

Ajoute une musique dans la queue locale.

## Utilisation

```text
!sr musique
```

## Exemples

```text
!sr Eminem Lose Yourself
!sr Lady Gaga Just Dance
!sr Angy xxxxx
```

## Liens supportés

```text
https://youtube.com/watch?v=XXXX
https://music.youtube.com/watch?v=XXXX
https://youtu.be/XXXX
```

# 🎵 !song

## Utilisation

```text
!song
```


# ⏭️ !next

Affiche la prochaine musique dans YTM Desktop.

## Utilisation

```text
!next
```

```text
⏭️ Prochaine musique : Lady Gaga - Just Dance
```

```text

```

---

# ⏭️ !skip

Passe la musique actuelle.

## Utilisation

```text
!skip
```

## Exemple

```text
⏭️ Musique skip avec succès.
```

---

# 🔥 !prio

Force immédiatement une musique après skip.

## Utilisation

```text
!prio musique
```

## Exemple

```text
!prio Eminem Without Me
```

Résultat :

```text
🔥 Viewer a utilisé un Skip Prio : Eminem - Without Me
```
