# ❤️ YTM SONG REQUEST SYSTEM V3

Développé par : **Godas DEV**

---

# 🚀 À propos

YTM GODAS V3 est un système avancé de Song Request pour :

```text
Firebot + YouTube Music Desktop
```

Le projet a été entièrement réécrit pour proposer :

```text
✅ Une vraie queue locale
✅ Un système stable
✅ Une meilleure précision
✅ Un Skip Prio réel
✅ Une gestion intelligente des SR
✅ Un système multi API Keys
```

---

# ⚡ Technologies utilisées

```text
- Firebot
- Node.js
- YouTube Data API v3
- YouTube Music Desktop
```

---

# 🔥 Fonctionnalités principales

```text
🎶 Song Request
⚡ Queue locale
🔥 Skip Prio
🔑 Multi API Keys
🧠 Recherche intelligente
🔄 Retry automatique
📜 Playlist locale
⏭️ Next / Skip
🧹 Clear queue
```
